vkoxide

Лёгкий асинхронный SDK и фреймворк для VK-ботов на Rust (Bots Long Poll API).

vkoxide — библиотека для написания ботов сообществ ВКонтакте. Вся работа асинхронна поверх tokio, маршрутизация событий — через предикаты-фильтры, ответы API — типизированы через serde.

use vkoxide::prelude::*;

#[tokio::main]
async fn main() {
    let bot = Bot::new(token, group_id);
    Dispatcher::builder(bot)
        .handler(schema())
        .build()
        .dispatch()
        .await
        .unwrap();
}
